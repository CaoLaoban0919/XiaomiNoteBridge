# 米记桥 · 权限清单

> 本文件有两个用途：**一、作为应用内「权限清单」页面的内容来源；二、作为开发时的核对基准。**
> 应用内展示的内容必须与本文件逐条一致。任何新增、扩大或删减，都必须同时更新本文件、协议第 5 条，以及界面上向用户的告知。

**版本 1.0　｜　对应应用版本 1.0　｜　最后更新：2026-10-14**

---

## 一、会申请的权限

| 权限 | macOS 中的位置 | 何时申请 | 用途 | 拒绝后的影响 |
| --- | --- | --- | --- | --- |
| **自动化** | 系统设置 → 隐私与安全性 → 自动化 →「备忘录」 | 首次执行同步时 | 向「备忘录」发送 Apple 事件：核验导入结果、建立笔记对应关系、更新小米端已修改的笔记 | 新笔记导入仍可用；「自动核验导入结果」与「同步已修改笔记」不可用 |
| **文件与文件夹** | 系统设置 → 隐私与安全性 → 文件与文件夹 | 首次写入输出目录时（仅当你选择的目录位于桌面 / 文稿 / 下载内） | 在你指定的目录中创建并写入 `.enex` 文件 | 无法生成导出文件，同步无法完成 |
| **网络** | 系统设置 → 网络（不单独授权） | 每次同步 | 连接 `i.mi.com` 读取你本人的笔记。**仅此一个域名** | 无法读取笔记，同步无法进行 |

## 二、视功能启用情况可能申请的权限

| 权限 | 何时申请 | 用途 | 拒绝后的影响 |
| --- | --- | --- | --- |
| **通知** | 你首次开启「同步完成时通知」时 | 同步完成或失败时发送系统通知 | 无通知，需回到应用查看结果 |
| **辅助功能** | 检测到「备忘录」导入时弹出确认对话框时 | 代为点击确认，使导入流程无需人工介入 | 每次导入需你手动点击确认 |
| **登录项与后台项目** | 你首次开启「定时自动同步」时 | 在后台按计划执行同步 | 只能手动点击同步 |

## 三、明确不申请的权限

本应用不会申请、亦不会使用下列任何权限：

通讯录　·　照片　·　相机　·　麦克风　·　位置信息　·　日历　·　提醒事项　·　健康数据
屏幕录制　·　输入监控　·　蓝牙　·　语音识别　·　**完全磁盘访问权限**　·　系统钥匙串

其中「完全磁盘访问权限」是权限范围最大的一项。本应用**在任何情况下都不会申请该权限**，也不需要它。

## 四、如何撤销

1. 打开 **系统设置**
2. 进入 **隐私与安全性**
3. 在左侧选择对应类别（自动化 / 文件与文件夹 / 通知 / 辅助功能 / 登录项）
4. 找到「米记桥」并关闭开关

撤销后，应用会在下次运行时检测到并给出对应提示，不会静默失败。

## 五、开发核对项

> 以下是实现时必须落实的技术动作，用于保证上面的清单不是空话。

| 项目 | 要求 |
| --- | --- |
| `Info.plist` → `NSAppleEventsUsageDescription` | 必须填写，内容需说明「用于核验导入结果、建立笔记对应关系、更新已修改的笔记」。此文本会出现在系统授权弹窗中 |
| `Info.plist` → `NSDesktopFolderUsageDescription` / `NSDocumentsFolderUsageDescription` / `NSDownloadsFolderUsageDescription` | 按需填写，用于输出目录落在这些位置时 |
| `entitlements` → `com.apple.security.automation.apple-events` | 设为 `true` |
| `entitlements` → `com.apple.security.network.client` | 设为 `true` |
| `entitlements` → `com.apple.security.app-sandbox` | **不启用**（本应用需要 Apple 事件与任意目录写入，沙盒下不可行）。此项须在协议第 5A(iii) 条中向用户说明 |
| 通知 / 辅助功能 / 登录项 | 仅在对应功能首次被启用时才调用申请 API，**严禁在启动时一次性全部申请** |
| 应用内「权限清单」页面 | 内容必须与本文件第一节至第三节逐条一致，并显示实际授权状态 |
| 权限变更 | 任何新增或扩大权限的版本，必须同时改本文件、协议第 5 条，并要求用户重新确认协议第 13B 条 |
